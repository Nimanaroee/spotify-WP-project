## محمدعقیل حافظی

### فاز اول (فرانت‌اند)
- راه‌اندازی اولیه‌ی پروژه: تعریف مدل‌های TypeScript (`ts`, `adding ts model`) و نگارش اسناد اسپک اولیه (`spec docs`).
- پیاده‌سازی پنل ادمین و پشتیبانی (`adding admin and support panel`).
- پیاده‌سازی پنل هنرمند و بخش نوتیفیکیشن (badge/page) و رفع مشکلات جهت متن RTL/LTR در پنل ادمین.
- رفع باگ‌های ریسپانسیو بودن رابط کاربری و اصلاح فرآیند تایید (approval) هنرمندان.
- ثبات‌بخشی به مدیریت state پخش موزیک (`consistent music store/play`).

### فاز دوم (بک‌اند)
- پیاده‌سازی اپلیکیشن‌های Django مربوط به مدیریت (`management`) و اعلان‌ها (`notifications`)، همراه با نوشتن تست‌های واحد (unit) و end-to-end برای این دو ماژول.
- افزودن مستندسازی API این دو ماژول به Swagger (drf-spectacular).
- رفع باگ‌های متفرقه و بازنویسی (refactor) لایه‌ی API client فرانت‌اند شامل افزودن منطق رفرش خودکار توکن (token refresh) و بهبود مدیریت پاسخ سرویس موزیک.

**حوزه‌ی اصلی کار:** زیرساخت اولیه پروژه، پنل ادمین/پشتیبانی/هنرمند در فرانت، و ماژول‌های `management` و `notifications` در بک‌اند، به‌همراه رفع باگ و بهبود لایه‌ی ارتباط با API.

## فاطمه طامهری

بیشترین حجم کامیت‌ها (۴۳ کامیت) و پرکارترین عضو تیم از نظر تعداد تغییرات، با کار در هر دو فاز.

### فاز اول (فرانت‌اند)
- پیاده‌سازی صفحات ورود و ثبت‌نام (`Implement login and register pages`).
- پیاده‌سازی صفحه‌ی مدیریت حساب (manage) و پروفایل کاربر عادی.
- افزودن قابلیت تم روشن/تاریک (dark/light theme) و رفع باگ‌های مربوط به آن.
- افزودن پشتیبانی از زبان دوم (فارسی/دوزبانه بودن رابط کاربری).
- پیاده‌سازی صفحه‌ی تنظیمات (Settings) و صفحه‌ی پروفایل هنرمند.
- بهبودهای متعدد رابط کاربری، افزودن فونت، و پیاده‌سازی PWA (Progressive Web App).
- به‌روزرسانی مستندات پروژه (`spec/`).

### فاز دوم (بک‌اند)
- راه‌اندازی اولیه‌ی اپلیکیشن‌های Django و پیاده‌سازی API های ثبت‌نام/ورود (`Initiate Django apps and implement register/login on backend`).
- پیاده‌سازی API های مدیریت پروفایل، manage، و دنبال‌کردن (follow) کاربران.
- پیاده‌سازی API های ترجیحات کاربر (preferences) و خروج از حساب (logout).
- رفع باگ در ذخیره‌سازی داده‌ی mock در فرانت و اصلاح مستندات Swagger.
- **پیاده‌سازی کامل ماژول پرداخت اشتراک:** افزودن منطق محاسبه‌ی هزینه‌ی اشتراک (`Implement upgrade subscription with fees`) و اتصال به درگاه پرداخت زرین‌پال (`Implement zarinpal gateway for payment`).
- هماهنگ‌سازی قیمت‌گذاری اشتراک با ماژول مدیریت (`Sync subscription pricing with management`).
- رفع باگ مربوط به چک‌باکس قوانین حریم خصوصی و اصلاح جریان ورود بعد از ثبت‌نام هنرمند.

**حوزه‌ی اصلی کار:** بیشتر صفحات اصلی فرانت‌اند (ورود/ثبت‌نام، پروفایل، تنظیمات، تم، PWA)، و در بک‌اند مسئول اصلی ماژول‌های `user` (احراز هویت و پروفایل) و **کل ماژول `payment`/درگاه زرین‌پال**.

## نیما کهدنارویی

### فاز اول (فرانت‌اند)
- ایجاد کامیت اولیه‌ی پروژه (`Initial commit`) و راه‌اندازی اسکلت اولیه‌ی ریپازیتوری.
- پیاده‌سازی صفحه‌ی اصلی (Home)، پلیر موزیک، و پلی‌لیست‌ها.
- رفع باگ‌های نوار پخش موزیک (music bar) و منو.
- افزودن قابلیت repeat mode و تاریخچه‌ی آهنگ‌های قبلی به پلیر.
- رفع مشکلات UI پلی‌لیست و چیدمان mini-app، و افزودن تست برای پلی‌لیست‌ها.

### فاز دوم (بک‌اند و اتصال فرانت-بک‌اند)
- اتصال فرانت‌اند به بک‌اند برای بخش آلبوم و پلی‌لیست (`connect front and back album and playlist`).
- دیباگ و بررسی رفتار پلیر موزیک پس از اتصال به API واقعی.
- پیاده‌سازی سیستم توصیه‌گر موزیک (music recommender) و ذخیره‌سازی ویژگی‌های صوتی برای پیش‌بینی (`add music rocommender and save music features for predicting`) — این بخش با فایل‌های `backend/music/recommender.py` و `backend/music/audio_features.py` مطابقت دارد.
- افزودن قابلیت تصویر پروفایل برای پلی‌لیست‌ها.

**حوزه‌ی اصلی کار:** پایه‌گذاری اولیه‌ی ریپازیتوری، پلیر موزیک و پلی‌لیست در فرانت، و در بک‌اند مسئول اصلی ماژول `music` شامل اتصال آلبوم/پلی‌لیست به API واقعی و سیستم توصیه‌گر موزیک (recommender).
